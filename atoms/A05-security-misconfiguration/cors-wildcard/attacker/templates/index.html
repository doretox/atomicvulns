Attacker page

Each link opens a page whose JavaScript makes a credentialed cross-origin fetch to the target's /account and shows whatever it can read:

  • Read the vulnerable target's account (victim.localhost:8034)
  • Read the fixed target's account (victim.localhost:8134)

Open with Burp proxy enabled to see the request on the wire; the read itself only happens in the browser.
